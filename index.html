🎯 DAS / ARR 정밀 조작 튜닝

환경설정 [조작 & 감도]에서 DAS(첫 이동 딜레이 100~300ms, 기본 150ms), ARR(연속 이동 15~80ms, 기본 33ms), 소프트드롭 배율(1x~20x, 기본 10x)을 조절합니다. PC 방향키와 모바일 7버튼 터치패드에 바로 적용됩니다.

💡 모바일은 보드 중앙 안내문을 터치해 시작하고, PC는 상단 [ ▶ 게임 시작 ]이 게임 중 [ ⏸ 일시정지 ] / [ ▶ 계속하기 ]로 바뀝니다.

🎯 보드 중앙 프로필 카드

대기·일시정지·게임 종료·레벨 20 정복 카드는 게임 패널(#board-wrap) 한가운데에 flex로 붙습니다. 오토플레이가 끝나도 카드가 오른쪽 아래로 밀리지 않습니다.

C1은 대기 카드와 정복 카드가 보드 기하 중심에 있는지 측정합니다. 레이아웃은 50%+translate가 아니라 오버레이 flex 중앙입니다.

📱 모바일 터치패드

세로 화면은 한 장(100dvh, 스크롤 없음)에 맞춥니다. 상단은 타이틀과 ⚙️설정·📖가이드·✏️진단 미니메뉴, 중앙은 좌측 10×20 게임 보드와 우측 기능타워(시작/종료, NEXT·HOLD, 2x2 점수판, AUTO, DAD 스페셜), 그 아래 가로 와이드 DAD 전광판, 최하단은 7버튼 터치패드입니다. 보드 중앙의 ‘게임 시작을 눌러 주세요’를 터치하면 바로 시작합니다.

  3. 3

자연 낙하나 소프트 드롭으로 바닥/블록 위에 안착하면 화면에 [3-2-1 카운트다운]이 시작됩니다.

카운트다운 중에는 블록 턱에 걸리지 않고 다른 블록을 자유롭게 넘나들며, 깊은 구멍(홈)이 있는 곳으로 이동하면 아래 바닥까지 쏙 내려앉아 완벽하게 배치할 수 있습니다.

💡 카운트다운 시간이 끝나더라도 걱정 마세요! 미처 자리를 정하지 못했을 경우 게임이 알아서 가장 최적의 명당자리에 블록을 자동으로 맞춰 드립니다.

❄️ 공중 타임스톱

K

공중에서 [K] 또는 모바일 [⏳]를 누르면 중력 낙하가 0ms로 멈춥니다. 제자리 회전·좌우 이동은 정지를 풀지 않습니다. 착지한 뒤 다음 블록에서 1턴에 1회만 다시 쓸 수 있습니다.

K / ⏳로 중력을 멈추고 제자리 회전. 착지 후 1턴에 1회만 다시 쓸 수 있습니다.

💡 타임스톱 중에는 [←/→] 이동, [↑] 회전도 정지를 풀지 않습니다. [Space] / [⚡]로만 즉시 착지합니다.

[환경설정]에서 3초(기본), 5초(여유), 10초(슈퍼 이지) 중 원하는 시간을 자유롭게 선택할 수 있습니다. 골든타임과 타임스톱에 함께 적용됩니다.

3초 (기본) 5초 (여유) 10초 (슈퍼 이지)

가비지 라인 · 동적 보드 크기

환경설정의 '시작 장애물 라인(0~10층)'을 설정하면 게임 시작 시 바닥에 구멍 뚫린 블록들이 미리 쌓인 상태로 시작하여 짜릿한 역전 클리어 챌린지를 즐길 수 있습니다.

보드 크기(낙하 거리 확장) 기능은 대화면 PC 전용 기능이며, 모바일에서는 최적의 터치 조작성을 위해 표준 규격(10×20칸)으로 자동 고정됩니다. PC에서는 표준 20칸, 롱 드롭 24칸, 울트라 타워 28칸을 고를 수 있습니다.

📏 게임 보드 세로 높이 (20 / 24 / 28칸) 📱 모바일 기본 20라인 전용

PC에서는 표준 20칸, 롱 드롭 타워 24칸, 울트라 타워 28칸으로 낙하 여유를 확보할 수 있습니다. 화면 너비 768px 이하 모바일은 터치 조작을 위해 표준 20칸으로 자동 고정되고, 보드 높이 선택 UI는 숨겨집니다.

🖼️ 윈도우 / 게임 패널 대기 배경 분리

윈도우와 패널, 대기와 Level 1~20은 서로 다른 IndexedDB 키입니다. 공유 키 bg_level_N은 사용하지 않습니다.

Idle 151020
  • 🖥️ 전체 윈도우: custom_bg_window_default / custom_bg_window_level_N, 윈도우 전용 블러/투명도. [전체 윈도우 배경 세트] 일괄 등록만 이 키에 저장됩니다.
  • 🎮 게임 패널: board_idle_bg_blob / custom_bg_board_level_N, 패널 전용 블러/투명도. [게임 패널 배경 세트] 일괄 등록만 이 키에 저장됩니다.
  • 윈도우 일괄 등록과 패널 일괄 등록은 동작·저장이 독립입니다. 공유 키(bg_level_N)를 쓰지 않아 한쪽 등록이 다른 쪽에 복사되지 않습니다.
  • 레벨이 오르면 윈도우는 custom_bg_window_level_N, 패널은 custom_bg_board_level_N을 각각 읽습니다. 레벨 커스텀이 없으면 등록해 둔 기본(Idle) 배경을 상속하고, 그것도 없으면 공통 시스템 배경 → level_N.jpg 순으로 폴백합니다. [기본 배경 고정]이 켜져 있으면 윈도우만 대기 배경을 유지합니다.
  • 🖼️ 스마트 배경 상속: 레벨별 전용 이미지가 없는 구간은 등록해 두신 기본 배경이 자동으로 이어져 표시됩니다.
  • 🌐 공통/개인 배경 분리: 가족 모두가 보는 '공통 배경'과 나만의 '개인 커스텀 배경'을 나누어 관리할 수 있습니다.

전체 윈도우와 게임 패널은 등록·저장·재생이 완전히 독립입니다. 패널에 올린 이미지가 윈도우에 섞이지 않으며, 블러·투명도와 [기본 배경 계속 유지]도 대상별로 동작합니다.

📦 배경 일괄 등록 & 스마트 전체 자동 분배

여러 장을 한 번에 고르면 스마트 엔진이 파일명으로 슬롯을 나눕니다.

환경설정 배경 탭에서 [전체 윈도우 배경 세트]와 [게임 패널 배경 세트]를 완전히 나눠 등록합니다. 한쪽 세트가 다른 쪽 저장 키를 덮지 않습니다. [스마트 전체 자동 분배]만 파일명 힌트로 대상을 나눕니다. 저장소는 IndexedDB(DadTetrisDB / media_files)입니다.

임의 이름도 대상별 정규 파일로 저장됩니다. 윈도우: default_bg.jpg / level_N.jpg, 패널: board_default_bg.jpg / board_level_N.jpg. IMG_0008.jpg의 숫자만으로는 레벨을 추정하지 않습니다.

  • 파일명 대기 / idle / wait → bg_idle (전체 윈도우 대기 배경)
  • [전체 윈도우 배경 세트] 1번째 → bg_idle, 2~16번째 → bg_lvl_1 … bg_lvl_15. 스마트 모드에서 lv숫자/레벨숫자면 해당 레벨
  • [게임 패널 배경 세트] 1번째 파일 → bg_panel_idle, 2~16번째 → bg_panel_lvl_1 … bg_panel_lvl_15. 스마트 모드에서 파일명 패널/panel/보드면 패널 슬롯
  • 윈도우/패널 세트는 파일 순서대로 대기→Lv.1~15(이후 파일은 Lv.16~20)에 넣습니다. 스마트 모드에서 이름 규칙이 없으면 앞 21장은 윈도우, 다음 21장은 패널입니다.

각 파일은 FileReader로 DataURL을 끝까지 읽은 뒤, IndexedDB readwrite 트랜잭션을 한 장씩 열어 put 완료를 기다립니다. 진행 바(#bulk-progress-bar)와 상태 문구가 실시간으로 갱신됩니다.

저장이 성공할 때마다 40×40 썸네일이 #bulk-preview-grid에 바로 추가됩니다. 끝나면 설정 슬롯(윈도우/패널)과 캔버스 배경이 즉시 갱신되고, 완료 메시지와 썸네일 리스트는 닫히지 않고 유지됩니다.

🖼️ 배경 커스텀 마스터 가이드

전체 윈도우 배경과 게임 패널 배경을 탭으로 나눠 각각 등록·삭제합니다. 저장 키와 일괄 등록 대상이 섞이지 않습니다.

  • 기본 배경 고정(keepDefault): 레벨이 올라도 대기(Idle) 배경을 유지합니다.
  • 배경 마스터 끄기(masterDisable): 등록 파일을 지우지 않고 기본 네온만 보여 줍니다.
  • 윈도우 블러/투명도 슬라이더로 전체 화면 배경의 흐림과 농도를 조절합니다.
  • 패널 블러/투명도 슬라이더로 게임 보드 뒤 배경만 따로 조절해 블록 가독성을 지킵니다.
  • 마스터 토글: 등록된 이미지를 삭제하지 않고 스위치 하나로 기본 네온 테마로 즉시 전환할 수 있습니다.
  • 윈도우 배경: 기본/레벨별 배경 등록, 기본 배경 고정 유지, 그리고 윈도우 전용 블러(흐림) 및 투명도 조절 기능을 지원합니다.
  • 게임 패널 배경: 패널 전용 레벨별 배경 등록과 패널 블러/투명도 듀얼 조절로 블록 시인성을 극대화할 수 있습니다.

💾 프로필 · 로컬 저장소

닉네임은 localStorage(dad_tetris_player_name)에 저장되고 빈칸이면 ‘시스템’으로 등록됩니다. 테마·스킨·볼륨·보드 높이는 localStorage, 대용량 사진·영상·BGM은 IndexedDB(DadTetrisDB / media_files) Blob에 분리 저장됩니다.

환경설정 [👤 플레이어 프로필 / 랭킹 설정]에서 게이머 닉네임을 지정합니다. 저장 키는 dad_tetris_player_name이며, 값이 없거나 빈칸으로 제출하면 무조건 ‘시스템’으로 등록됩니다. 자동 기록 모드도 이 닉네임을 사용합니다.

환경설정에서 언어를 바꾸면 UI가 즉시 바뀝니다. 기본은 한국어이며 영어, 힌디어, 중국어 간체, 스페인어, 일본어, 프랑스어, 독일어, 포르투갈어, 러시아어, 베트남어, 인도네시아어를 지원합니다. 선택은 localStorage(tetris_lang)에 저장됩니다.
