윈도우와 게임 패널의 기본 배경 이미지는 '개별 직접 등록' 방식과 '스마트 일괄 등록' 방식 중 편한 방법으로 저장할 수 있습니다.

1. 개별 직접 등록 방식

전체 윈도우 기본 대기 배경:

⚙️ 환경설정 ➜ 🖥️ 전체 윈도우 배경 탭으로 이동합니다.

[🖼️ 기본 대기 배경 이미지] 카드에서 🖼️ 이미지 선택 버튼을 눌러 원하는 사진을 선택합니다.

선택 즉시 우측 썸네일에 미리보기가 뜨며, 브라우저 내부 고용량 저장소(IndexedDB)에 자동 영구 저장됩니다.

게임 패널(테트리스 판) 기본 대기 배경:

⚙️ 환경설정 ➜ 🎮 게임 패널 배경 탭으로 이동합니다.

[🖼️ 게임 패널 기본 대기 배경 이미지] 카드에서 🖼️ 이미지 선택 버튼을 눌러 패널 전용 이미지를 선택합니다.

선택 즉시 대기 화면 및 게임 오버 화면의 게임 패널 배경으로 자동 저장·적용됩니다.

2. 스마트 일괄 등록 방식 (추천)

여러 장의 사진을 한 번에 정리하여 등록할 때는 파일명에 키워드를 넣고 일괄 등록을 사용하면 가장 빠릅니다.

파일명 규칙 설정:

전체 윈도우 대기 배경으로 쓸 파일 이름에 대기 또는 idle 포함 (예: 가족사진_대기.jpg)

게임 패널 대기 배경으로 쓸 파일 이름에 패널, 보드, panel 포함 (예: 패널_배경.png)

일괄 등록 실행:

⚙️ 환경설정 상단의 [📦 배경 일괄 등록] 섹션으로 이동합니다.

라디오 옵션을 스마트 전체 자동 분배로 선택합니다.

📁 여러 파일 선택 버튼을 누르고 준비한 사진들을 한 번에 모두 드래그하여 선택합니다.

프로그레스 바가 100%까지 차오르며, 키워드를 인식해 윈도우 대기 배경과 게임 패널 대기 배경으로 각각 자동 분류 저장됩니다.

3. 게임 플레이 중에도 대기 배경을 유지하고 싶을 때

레벨이 올라가도 등록한 기본 배경이 바뀌지 않고 계속 유지되길 원하신다면, 각 배경 탭 상단에 있는 📌 기본 배경 계속 유지 (레벨업 시 변경 안 함) 토글 스위치를 ON으로 켜두시면 됩니다.
